# Journal — 2026-09-28

## Objetivo del día
Agregar el scraper de Revolico y completar el `.gitignore`.

## Actividades realizada
- Se creó `scripts/scraper_revolico.py` con el pipeline completo de scraping.
- Se implementó el respeto a `robots.txt` usando `RobotFileParser` con sesión HTTP.
- Se configuraron delays aleatorios de 3-5 segundos entre peticiones.
- Se implementó el sistema de logging con niveles DEBUG/INFO/WARNING/ERROR.
- Se completó `.gitignore` para excluir `logs/` y otros archivos generados.

## Problemas encontrados y soluciones
- **Revolico es una SPA de Next.js:** Los datos no están en el DOM sino en `__NEXT_DATA__` → `__APOLLO_STATE__`. Se adaptó el scraper para extraer del JSON embebido.
- **Bug con `RobotFileParser.read()`:** Usaba `urllib` con User-Agent `Python-urllib/3.13` y recibía 403. Se corrigió usando `session.get(robots.txt)` + `rp.parse()`.
- **Slugs inexistentes:** `inmobiliaria-apartamentos` e `inmobiliaria-solares` devuelven HTTP 500. Solo existen `inmobiliaria-casas` e `inmobiliaria-otros-inmobiliaria`.

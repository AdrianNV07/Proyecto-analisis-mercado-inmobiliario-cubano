# Journal — 2026-09-29

## Objetivo del día
Corregir los regex de baños y habitaciones para el scraper.

## Actividades realizadas
- Se corrigió el regex de baños: los rangos `N/M` (ej. "2/3 baños") ahora toman la **parte baja** (interpretación conservadora).
- Se implementaron 4 estrategias para extraer baños:
  1. Rango `N/M` → parte baja.
  2. Cantidad explícita ("2 baños", "un baño", "3 wc").
  3. Singular sin cantidad → inferido (`banos_inferido = True`).
  4. Plural sin cantidad → `None`.
- Se corrigió el regex de habitaciones con el mismo criterio.

## Problemas encontrados y soluciones
- **Ambigüedad en rangos:** "2/3 baños" podía interpretarse como 2 o 3. Se decidió tomar el mínimo para no sobreestimar.
- **Inferencias vs. extracciones:** Se añadió el flag `banos_inferido` para distinguir valores deducidos de valores explícitos. En el análisis solo se usan `banos_inferido == False`.
